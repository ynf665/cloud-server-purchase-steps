## 下单前先想清楚三件事

买云服务器最难的部分发生在付款页面之前。地域、配置、计费方式这三项决定了你花钱的效率，而且地域这项买了就改不了。

### 地域选了就改不了

云服务器的地域（数据中心所在城市）在创建后无法修改，买错了只能退掉重买，中间的折腾都是成本。判断标准很简单：你的访问者在哪里。个人博客没有明显地域倾向，选离自己近的大陆地域就行；主要服务特定地区用户，就选离他们近的节点。

还有一件事必须在选地域前想好——**备案**。域名要解析到中国大陆地域的云服务器对外提供网站服务，必须先完成工信部ICP备案，未备案的域名会被拦截。备案本身免费，但流程走下来通常要一到两周。赶时间，或者只是自己学习测试，可以选中国香港等海外地域，域名不用备案就能访问，代价是大陆用户访问延迟会高一些。

### 配置按用途选，不按感觉选

1核2G够个人博客、学习环境、轻量脚本使用；企业官网、日访问几千到上万的小型应用，从2核4G起步比较稳。再高的配置先不用想，云服务器支持后期升降配，先买小的跑起来，不够再升，比一步到位买大了划算。

带宽同理。1到3M固定带宽够个人站点用，阿里云的带宽后期随时可以升级。

### 计费方式决定你花多少钱

- **包年包月**：先付费，按月或按年买，长期使用最划算，99元/年的特价机就是这种模式
- **按量计费**：按秒计费、按小时出账，用几小时付几小时，适合临时测试；用完记得释放实例，否则会一直扣费
- **竞价实例**：价格比按量计费低，但库存紧张时可能被自动回收，只适合丢了也不心疼的无状态任务

长期使用直接选包年包月，只有“就要用几天”的场景才值得考虑按量。

## 几个高频问题

**个人用买多大配置合适？**
1核2G或2核2G起步就够。个人博客、课程实验、小工具后端，这个档位能覆盖大多数场景，卡了再升，升级只需补差价。

**域名一定要备案吗？**
只有当域名解析到中国大陆地域的服务器、通过域名对外提供网站服务时才需要。用IP调试，或服务器选在中国香港及海外地域，都不涉及备案。

**活动机和自定义购买能同时用吗？**
能。活动机就是一份普通的包年包月订单，之后再通过自定义购买加购第二台、第三台都行，互相不影响。

**买错了能退吗？**
5天无理由退款期内可以退。超过期限，按量计费的实例释放后即停止计费，包年包月的只能等到期，或者提工单协商。
